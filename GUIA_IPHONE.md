# Guia de Uso no iPhone

## Instalação da PWA

1. Abra o Leak Stop CRM no Safari
2. Toque no botão Compartilhar (share icon)
3. Selecione "Adicionar à Tela de Início"
4. Nomeie como "Leak Stop CRM"
5. Toque em "Adicionar"

## Uso

- A aplicação funcionará offline (quando disponível no cache)
- Sincronização automática quando conectado à internet
- Interface otimizada para tela de toque

## Troubleshooting

- Limpe o cache: Configurações > Safari > Limpar Histórico e Dados do Site
- Reinstale a PWA seguindo os passos acima
