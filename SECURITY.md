# Política de Segurança

## Relatório de Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança, envie um email para security@leakstop.com

## Boas Práticas

1. Mantenha as dependências atualizadas
2. Use variáveis de ambiente para credenciais
3. Implemente validação de entrada
4. Use HTTPS em produção
5. Ative CORS apenas para domínios confiáveis

## Verificação de Segurança

Execute regularmente:

```bash
npm audit
```
