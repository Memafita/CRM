Política de Privacidade

Última atualização: 02/07/2026

Importante: este modelo deve ser revisado pelo responsável do negócio antes de circular publicamente. Preencha os dados de contato do controlador.

1. Finalidade

O Leak Stop CRM é utilizado para organização de prospecção comercial, acompanhamento de contatos, registro de status de negociação e exportação de relatórios operacionais.

2. Dados tratados

Podem ser registrados dados como nome do negócio, telefone comercial, segmento, origem do lead, valor estimado/fechado, status comercial e observações inseridas pelo usuário.

3. Base e responsabilidade

O usuário responsável pelo workspace é o controlador dos dados que inserir no CRM. A coleta deve respeitar a legislação aplicável, incluindo a LGPD, princípios de necessidade, transparência e finalidade legítima.

4. Armazenamento

Por padrão, os dados ficam salvos localmente no navegador do usuário. Quando a sincronização é ativada, os dados são enviados para o banco Supabase configurado pelo responsável do CRM por meio de função segura no Netlify.

5. Compartilhamento

Os dados não devem ser vendidos ou compartilhados com terceiros sem base legal e informação adequada ao titular. Fornecedores técnicos, como hospedagem e banco de dados, podem processar os dados apenas para execução do serviço.

6. Retenção e exclusão

O usuário deve manter os dados apenas pelo tempo necessário para a finalidade comercial. Leads podem ser excluídos no CRM e a exclusão é sincronizada quando a nuvem estiver configurada.

7. Direitos dos titulares

Solicitações de acesso, correção, descadastro ou exclusão devem ser atendidas pelo responsável do workspace.

8. Segurança

Não insira senhas, dados bancários, documentos sensíveis ou informações desnecessárias no campo de observações. Chaves de sincronização devem ser mantidas em sigilo e rotacionadas em caso de vazamento.
