# Leak Stop CRM - Netlify Ready

Sistema de Gerenciamento de Relacionamento com Cliente (CRM) otimizado para Netlify.

## 🚀 Características

- Interface responsiva
- Gerenciamento de prospectos
- Sincronização em tempo real
- PWA (Progressive Web App)
- Serverless functions com Netlify

## 📋 Requisitos

- Node.js 14+
- npm ou yarn
- Conta Netlify

## 🔧 Instalação

```bash
npm install
```

## 🚀 Deploy no Netlify

1. Conecte seu repositório GitHub ao Netlify
2. Configure as variáveis de ambiente no painel Netlify
3. Ative o deploy automático

## 📁 Estrutura

```
.
├── netlify/
│   └── functions/
│       └── sync-prospectos.js
├── index.html
├── sw.js
├── schema.sql
└── netlify.toml
```
